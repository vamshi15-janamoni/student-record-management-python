# Student Record Management System

A beginner-friendly Python project for **Module 2: Functions, Files & Exception Handling**.

## Features

- Add student records
- View all student records
- Update student records
- Delete student records
- Search students (JSON version)
- Store data using JSON
- Alternative CSV implementation
- Functions and parameters
- Return values
- Lambda and list-comprehension examples
- File handling
- `try-except-finally` exception handling
- Input validation and basic debugging

## Requirements

- Python 3.9 or newer
- No external packages required

## Run the JSON version

```bash
python student_management.py
```

The program creates/updates `students.json`.

## Run the CSV version

```bash
python student_management_csv.py
```

The program creates/updates `students.csv`.
